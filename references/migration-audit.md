# DSH → WorkBuddy 迁移取舍

## 保留并前置的方法

- 从原文论点和关系类型出发，而非从参考图外观出发。
- 结构→组分→素材，素材负责形象，SVG 负责确定性装配。
- 改图前列可验收清单；复杂项目先隔离副本，再确定单一生成器。
- 每个关键元素有稳定 ID、注释和语义；几何、声明语义、科学内容和独立盲读分层审查。
- “多行文字＋短箭头”不等于空间机制网络；过程节点、可见目标命中和长连线路由优先。
- 评分只做同口径回归，不能替代科学正确性和真实可读性。

## 重构的矛盾

- 双向交换的多种互相矛盾画法改为“项目内统一且图例可解码”。
- BioRender 绝对化要求改为“授权可追溯素材优先，自绘和开放素材允许”。
- 英文要求改为英文期刊默认策略，中文/双语项目由用户配置。
- 三轮/四轮/五轮审核统一为转录、位置、作用、整体逻辑、因果链五个维度。
- “降分即回退”改为“定位并局部修复；不得为追分删除必要机制”。
- “包围盒内即命中”改为“真实路径、可见轮廓、透明区和遮挡共同检查”。
- 固定区域审查改为覆盖本图所有关键区室和跨区室连接。

## 未迁移的高风险内容

- 账号、邮箱、凭据路径、Cookie、浏览器 profile、API key 和原自动登录流程；新版仅提供经用户明确授权的本地私有凭据适配器，密码不进入技能包。
- 删除云端画布、强制结束 Photoshop、固定临时目录清空和固定屏幕坐标操作。
- 规避平台导出、授权或水印限制的建议。
- 固定模型、套餐、端点、token、像素门槛及特定服务商参数。
- 本机绝对路径、固定 Python/Node/Photoshop、DSH 专有工具和未随包提供的 `_probe` 命令。
- 原 `ps_cut.ps1`、旧备份、一次性补丁和项目私有医学答案。

## 重写的工具

原技能引用的许多脚本并未随包提供，且部分工具只检查直线或包围盒。WorkBuddy 版重新实现：

1. `render_svg.py`：显式输入输出、区域渲染、浏览器自动发现和元数据；
2. `audit_figure.py`：自描述/外部 spec、真实路径端点、引用、语言、区域和透明度辅助检查；
3. `make_blind_panels.py`：中性公开材料与私有映射隔离，不联网、不调用模型。

核心工具不读取凭据、不自动联网、不删除用户文件。科学机制与项目目标表放在用户项目配置中，不写入通用脚本。
