# 机制图设计与视觉语法

## 1. 先确定关系，再确定图型

将一句话论点拆成读者必须复述的关系：

| 科学关系 | 推荐结构 | 禁止误画 |
|---|---|---|
| 并列/分类 | 同层分组、树状分类 | 为显得高级而强加箭头 |
| 因果/信号 | 输入→事件节点→输出 | 把相关性画成确定因果 |
| 时序/状态变化 | 同一结构的状态序列 | 用多个无关图标代替过程 |
| 对照/镜像 | 同构的左右网络及少量关系摘要 | 只比较关系词而丢失胞内过程 |
| 双相/语境依赖 | 明确条件、剂量、时程或细胞类型分支 | 用单一上升/下降掩盖条件 |
| 跨区室作用 | 细胞器空间网络和跨区室路径 | 多行文字加短箭头 |

参考先例时分别记录可核对的结构参数（区块、路径、数量、连接、方向）和组分参数（素材、形态、颜色、标签）。无合适先例时记录 `NO-PRECEDENT + 设计理由`，不得虚构先例。

## 2. 空间机制网络的最低要求

- 使用细胞器或区室的相对位置承载科学意义；所有膜受体、转运体和区室特异事件放在正确位置。
- 用素材状态变化表示过程，例如完整→分裂→损伤→自噬→清除，避免把同一素材复制成列表。
- 给分子输入、机制事件、细胞命运和组织结局明确起点与终点。
- 过程汇聚使用实体节点；每条输入和输出落在节点的不同边缘，避免多个箭头指向文字附近空白。
- 长连线先规划走廊。多段三次曲线可属于同一条连续路径，但不得出现方向不明的断线。
- 标签依附于结构或作用线。结构名、区室名和图例不必拥有机制箭头；只有机制事件节点需要检查断链。

## 3. 科学定位与作用符号的强制交叉检查

- 将胞外刺激放在细胞外或跨膜入口；不要让 High Pi、乳酸等输入看起来像已经位于核内，除非证据明确如此。
- 将受体放在真实膜区室。例如 TNFα 的受体应在质膜，不得为了靠近下游 ER 通路而把受体画在 ER 上。
- 将保护性输出用抑制端连接病理结局。例如 Klotho 抑制钙化不能使用普通激活箭头；PPARγ 激动剂激活受体不能使用抑制端。
- 将主要分支汇入细胞命运/组织结局，或明确标为独立观察。不要让自噬、保护通路或代谢支路成为没有出口的机制孤岛。
- 优先使用可追踪的短路径；长回线若成为视觉主线，应重新布局，而不是依赖读者沿线绕行。
- 区分同一底物的不同膜转运体：质膜磷转运体（如 PiT-1）与线粒体内膜载体（PiC）不得混用；胞外输入→质膜转运→胞质→细胞器载体的路径必须闭合。
- 将转运体与胞质酶分开定位，例如 SLC7A11 与 GPX4 不得因写在同一标签就都被读成质膜转运体。
- 将膜型/分泌型保护因子放在合适区室，不默认放在细胞核内；核内受体到保护性输出再到病理结局的方向需可追踪。
- 最终组织图标必须由结局节点明确接线，不能只靠与文字相邻来表达因果。
- 在审计 spec 中为关键边写 `relation`，并用 `relation-mismatch` 检查实际 SVG 图形与声明是否一致。

## 4. 视觉语法必须可解码

在项目内统一并由图例定义：

- 激活/流向、抑制、减弱或间接作用、转位、双向交换、接触、代谢底物输入。
- 实线、虚线、T 形端、颜色和箭头形状的含义；不要只依赖颜色传达关键差异。
- 双向交换可采用双头箭或一对反向箭头，但同一项目只选一种体系，不混用相互矛盾的画法。
- 上升/下降符号需说明是表达量、活性还是过程强度；无定量变化含义的分子不强行添加。

同一语义作用域、同一关系和同一方向的重复箭头才去重。左右对照、不同状态或不同面板中的有意重复不得误删。

## 5. 科学边界

- 不因“看不出因果”就自动补箭头；先回原文确认是否存在因果证据。
- 不因图注与正文冲突就直接以图注为准；回查原始证据，必要时请用户确认。
- 不用预设的器官比例、细胞形状或固定细胞器位置替代具体科学审查。
- 将不确定、推测、细胞类型特异和证据不足的内容显式标注或移出图内主干。

## 6. 代码与画面相互核对

每个关键元素同时具有代码注释和机器可读 ID。注释说明“表示什么、从哪里到哪里、证据是什么”，渲染后逐项核对：

- 注释中的素材是否就是该位置的素材；
- 箭头两端是否就是注释声明的对象；
- 虚线、引线和箭头头是否真实可见；
- 是否出现同义重复、孤立标签或与注释相悖的图形。
