# 审计与独立盲读协议

## 1. 审计顺序

1. **源文件**：XML 可解析、ID 唯一、资源存在、引用完整、图内语言符合项目策略。
2. **几何**：真实路径起止、目标距离、元素出界、文字/素材压叠、路径穿文字或无关结构。
3. **声明语义**：source/target/relation 与设计一致，关键过程节点无断链，同语义作用域无重复连接。
4. **可见性**：箭头头未被上层素材覆盖，端点落在可见轮廓而非透明区；图例能解码图内非标准符号。
5. **科学复核**：逐项对照正文，识别模型或图注中的科学错误。
6. **独立盲读**：由未接触设计答案的审阅者重建流程。
7. **评分回归**：同口径比较旧版与新版，不以评分替代上述检查。

碰撞为零、端点距离为零或医学术语齐全均不能单独证明图正确。

## 2. 自描述 SVG 与项目 spec

新图优先写入 `data-source-id`、`data-target-id`、`data-relation` 和 `data-meaning`。旧图用外部 JSON spec 补充，不把目标映射硬编码到审计器。

```json
{
  "version": 1,
  "edges": [
    {"id": "A01", "target": "NODE_B", "check_source": false},
    {"id": "A02", "source": "NODE_B", "target": "NODE_C", "check_source": true}
  ],
  "required_edges": ["A01", "A02"],
  "ignore": ["LEG-*"],
  "text_policy": "no-cjk",
  "regions": [
    {"name": "central", "selector": "^M[0-9]+-NAME$", "bbox": [800, 0, 1000, 1360]}
  ]
}
```

脚本从 `<line>` 或 `<path>` 读取真实起止；`data-x1/data-x2` 只作辅助信息，不能替代路径。容差按 SVG viewBox 单位设置。

## 3. 盲读包隔离

目录分为：

- `public/`：中性文件名整图、局部图和通用问题，供审阅者使用；
- `private/`：原图 hash、区域 ID、坐标、偏移、随机种子和映射，仅供设计方揭盲后使用。

公开材料不得出现原稿、生成器、图注、区域语义文件名、目标表、预期答案或设计讨论。审阅者不得读取技能中的案例。

## 4. 五维盲读问题

要求审阅者只根据图片回答：

1. **转录**：能看到哪些细胞器、分子、文字和升降？哪些看不清？
2. **位置**：每个效应发生在细胞膜、胞质或哪个细胞器？依据是什么？
3. **作用**：每条箭头/虚线/抑制线从哪里出发、实际指向哪里、方向是什么？
4. **整体逻辑**：左右或各面板是什么对象，关系词和结局是什么？
5. **因果链**：按顺序复述输入、状态变化、跨区室作用、细胞命运与组织结局。

必须主动询问：哪些线指空、指歪、误指到邻近结构、被遮挡、重复或只能靠猜？不允许利用常见通路替图片补全。

复杂图应覆盖所有关键区室及跨区室连接的高清局部。局部裁图导致的正常画外线不计为原图缺陷，应结合整图追踪。

## 5. 独立性与复查

- 同一模型的新上下文可构成独立审阅；两个不同品牌模型若共享设计答案则不独立。
- 当前设计会话中的再次自审不能冒充独立盲读。
- 经用户同意，可分派多个全新视觉代理分别审查整图、左右局部和箭头目标。
- 引导式追问、指出具体区域后的复核必须标记为“非独立复查”。
- 服务不可用、图片过大、超时或模型缺失记为 `NOT_ASSESSED`，不得写成通过或“图不可读”。

保存审阅者、上下文隔离方式、图片 hash、原始回答和状态。揭盲后逐项对照证据矩阵；答错或答不出的地方先修图再重测，不用设计意图替审阅者补答案。
